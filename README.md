Unit IV – Stacks and Queues

This repository contains C++ implementations of Stack and Queue data structures using arrays and linked lists.

Practical Programs

1. Stack Using Array

File: "stackarraywith.cpp"

Implements stack operations such as push, pop, peek, display, and checking whether the stack is full or empty.

2. Queue Using Array

File: "queuewitharray.cpp"

Implements enqueue, dequeue, peek, display, and checking whether the queue is full or empty.

3. Stack Using Linked List

File: "stacklinkedlist.cpp"

Implements stack operations using dynamically allocated linked-list nodes.

4. Queue Using Linked List

File: "queuewithlist.cpp"

Implements queue operations using linked-list nodes and front and rear pointers.

Concepts Demonstrated

- Stack follows the LIFO principle (Last In, First Out).
- Queue follows the FIFO principle (First In, First Out).
- Arrays provide fixed-size storage.
- Linked lists use dynamically allocated nodes.
- Pointers are used to connect and manage linked-list nodes.

How to Compile and Run

Install a C++ compiler such as GCC.

Example for Stack Using Array:

g++ stackarraywith.cpp -o stackarraywith

Run on Windows PowerShell:

.\stackarraywith.exe

Repeat the same procedure with the other three source files.
